# Deploiement Coolify

Application Node.js 24 et SQLite, sans dependance npm externe.

## Source et construction

- Depot : https://github.com/GamePartsOnline/La-X-des-arts
- Branche : main
- Build pack : Dockerfile
- Dockerfile : /Dockerfile
- Port interne : 3000
- Controle de sante : GET /api/health
- Un seul replica, stockage local SQLite.

## Stockage persistant

Ajouter un volume nomme croisee-data, destination /data.
La base school.sqlite contient les comptes, sessions, progressions et fichiers binaires.
Le processus tourne avec UID/GID 1000. Le volume doit etre accessible en ecriture a cet utilisateur.
Sauvegarder la base avec l'API SQLite backup, ou arreter le conteneur et copier le dossier /data complet, y compris les fichiers WAL et SHM s'ils existent.

## Variables au demarrage

APP_ORIGIN=https://domaine-final
DATA_DIR=/data
ADMIN_EMAIL=adresse-du-tuteur
ADMIN_NAME=nom-du-tuteur
ADMIN_PASSWORD=secret-de-12-caracteres-minimum
STUDENT_EMAIL=adresse-du-stagiaire
STUDENT_NAME=nom-du-stagiaire
STUDENT_PASSWORD=autre-secret-de-12-caracteres-minimum

Saisir les mots de passe comme secrets runtime dans Coolify, jamais en variables de build ni dans Git.
Les comptes sont crees au premier demarrage. Une adresse existante n'est jamais ecrasee.
Retirer ensuite les variables de mots de passe : les comptes restent dans le volume.
Aucun compte ni mot de passe par defaut.

## Utilisation locale

Node.js 24 minimum. npm test puis npm start.
Creation de compte supplementaire : definir ACCOUNT_PASSWORD dans l'environnement puis
npm run account -- adresse@example.com Nom admin
ou remplacer admin par stagiaire.

## Validation

npm test : authentification, refus des acces intercomptes, droits tuteur,
validation des lecons, verrouillage graphisme, fichiers binaires,
notation manuelle, refus des origines externes et deconnexion.
Les anciens progres locaux du navigateur ne sont pas importes : ils provenaient du mode demonstration.
La base, les secrets et les captures sont exclus de Git.
Le deploiement et la verification visuelle de l'interface restent a effectuer sur Coolify.
