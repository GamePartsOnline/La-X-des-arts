# Deploiement Coolify & Configuration du Domaine `laxdesarts.gposarl.com`

Application Node.js 24 et SQLite, sans dependance npm externe.

## 1. Remplacer l'adresse `sslip.io` par `laxdesarts.gposarl.com`

Pour remplacer `https://x7k8orymdtzotwdncyfwiuuj.37.59.104.240.sslip.io/` par `https://laxdesarts.gposarl.com` :

1. **Zone DNS (`gposarl.com` chez OVH / votre registrar)** :
   - Ajouter un enregistrement de type **A** :
     - Sous-domaine (Host) : `laxdesarts`
     - Cible (Value) : `37.59.104.240`
     - TTL : par defaut (ou 300 s)
2. **Configuration de la ressource dans Coolify (`https://coolify.gposarl.com`)** :
   - Ouvrir le projet et l'application **La Croisee des Arts**.
   - Dans l'onglet **General** -> champ **Domains**, remplacer `https://x7k8orymdtzotwdncyfwiuuj.37.59.104.240.sslip.io` par :
     `https://laxdesarts.gposarl.com`
   - Cliquer sur **Save** (Traefik / Caddy generera automatiquement le certificat SSL Let's Encrypt).
3. **Variable d'environnement `APP_ORIGIN` dans Coolify** :
   - Dans l'onglet **Environment Variables**, mettre a jour :
     `APP_ORIGIN=https://laxdesarts.gposarl.com`
   - Cliquer sur **Redeploy** (ou **Restart**) pour appliquer la nouvelle origine de securite CSRF et le cookie `Secure`.

## 3. Stockage persistant

Ajouter un volume nomme `croisee-data`, destination `/data`.
La base `school.sqlite` contient les comptes, sessions, progressions et fichiers binaires.
Le processus tourne avec UID/GID 1000.
